# gnarl-render

Gnarl: CPU-side render batches in Gource's fixed pass order (no GL).

Part of [Gnarl](https://github.com/dfadler/Gnarl), a Rust port of [Gource](https://gource.io/), published as a building block of the `gnarl` binary; it has no stability promise of its own and its API follows the application's needs. Licensed GPL-3.0-or-later.
