# gnarl

Gnarl: a Rust port of Gource, the software version control visualization (windowed and headless frame export).

```sh
cargo install gnarl --locked
gnarl --help
```

See the [project README](https://github.com/dfadler/Gnarl#readme) for install options (release
tarballs, container image), system requirements and the optional `pcre2` feature.

Gnarl is a port of [Gource](https://gource.io/). Licensed GPL-3.0-or-later.
